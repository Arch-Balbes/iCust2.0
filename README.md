# iCust MVP

Сервис для проведения и анализа проблемных (CustDev) интервью: от описания продукта до отчёта.

1. **Дизайн исследования** — по анкете продукта генерируются гипотезы сегментов и ценности, сценарий интервью,
   план поиска респондентов и документ дизайна.
2. **Интервью** — записи загружаются в сервис, расшифровываются с разделением собеседников, обезличиваются.
3. **Анализ** — ответы раскладываются по вопросам сценария, делятся на утверждения и сверяются с компонентами
   гипотез; по каждой гипотезе считается доля подтверждённых элементов, выделяются инсайты.
4. **Отчёт** — выгрузка в .docx / .md и пакет результатов в JSON.

## Стек

| Сервис | Технологии |
|---|---|
| `frontend` / `gateway` | React, TypeScript, Vite, TanStack Query; Nginx (статика и прокси `/api`) |
| `api` | FastAPI, SQLAlchemy 2 (async), Alembic, Pydantic |
| `worker` | arq (Redis) — фоновые задачи: генерация, расшифровка, анализ |
| `design` | модуль генерации дизайна исследования (FastAPI, sentence-transformers) |
| `postgres` | PostgreSQL 17 + pgvector |
| `redis` | очередь задач |
| `minio` | S3-совместимое хранилище записей |

Внешние API: LLM — Cloud.ru Foundation Models, распознавание речи — Nexara.

## Запуск

Нужны Docker и Docker Compose.

```bash
cp .env.example .env                 # пароли БД и хранилища (на Windows: scripts/new-env.ps1 сгенерирует случайные)
cp secrets.env.example secrets.env   # ключи CLOUDRU_API_KEY и NEXARA_API_KEY
docker compose up -d --build
```

- Приложение: http://localhost:8090
- Документация API: http://localhost:8090/api/docs

Сервису `design` при первом старте нужна база знаний (размеченные данные исследований, путь —
`data/design/raw/<снапшот>`, в репозиторий не входят) и загрузка моделей поиска (~4,5 ГБ).

## Структура

```
backend/    API, фоновые задачи, модели данных, миграции
design/     модуль генерации дизайна исследования
frontend/   веб-интерфейс и конфигурация шлюза
scripts/    служебные скрипты
```

Файлы `.env` и `secrets.env` содержат пароли и ключи и не должны попадать в репозиторий.
